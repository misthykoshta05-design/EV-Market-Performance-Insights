Electric Vehicle Market Performance & Insights

📌 Project Overview

The Electric Vehicle Market Performance & Insights project focuses on analyzing electric vehicle (EV) market data to understand market trends and performance across different categories, regions, and years.

The project uses Tableau to create interactive visualizations and dashboards that help users explore EV market insights. A Flask-based web application integrates the Tableau Dashboard and Story into a single webpage for easy access.

🎯 Objectives

- Analyze electric vehicle market performance.
- Explore trends across different years and regions.
- Present market insights through interactive visualizations.
- Integrate the Tableau Dashboard and Story with a Flask web application.

🛠️ Technologies Used

- Python
- Flask
- HTML
- Tableau Public
- CSV Dataset
- GitHub

📊 Project Features

- Interactive Tableau Dashboard
- Tableau Story with key insights
- EV market data analysis
- Flask-based web interface
- Easy navigation between the Dashboard and Story
